## 1. ログイン機能

### 画面：`/login`

#### 概要
スタッフがシステムにログインする画面。

#### 入力項目

| 項目 | 形式 | 必須 | 説明 |
|---|---|---|---|
| メールアドレス | email | ○ | Supabase に登録されたメールアドレス |
| パスワード | password | ○ | 登録済みパスワード |

#### 処理仕様
- 「ログイン」ボタン押下時、Supabase Auth の `signInWithPassword` を呼び出す
- 認証成功時：`/dashboard` にリダイレクト
- 認証失敗時：「メールアドレスまたはパスワードが正しくありません。」を表示

#### その他
- 認証済みユーザーがアクセスした場合、`/dashboard` に自動リダイレクト
- ログアウトはナビゲーションバーの「ログアウト」ボタンから実行

## 2. ダッシュボード機能

### 画面：`/dashboard`

#### 概要
本日の来訪状況と今後の予定を一目で確認できるトップ画面。

#### 表示内容

**サマリーカード（4件）**

| カード | 内容 |
|---|---|
| 本日の来訪 | 本日の来訪件数（キャンセルを除く） |
| 入室中 | 現在入室中の件数（status = checked_in） |
| 完了 | 本日退室済みの件数（status = completed） |
| 累計来訪 | 全期間の来訪件数合計（キャンセルを除く） |

**本日の来訪一覧**
- 本日（scheduled_date = 今日）かつキャンセル以外の来訪を登録順に表示
- 表示項目：会社名、代表来訪者名、人数、担当者名、入退室時刻、ステータスバッジ
- 各行クリックで来訪詳細画面へ遷移

**今後の来訪予定**
- 明日以降で status = scheduled の来訪を最大5件表示
- 表示項目：会社名、来訪予定日、代表来訪者名、ステータスバッジ

---

## 3. 来訪者事前登録機能

### 画面：`/visits/new`

#### 概要
スタッフが来訪者の情報を事前に登録する画面。

#### 入力項目

| 項目 | 形式 | 必須 | 説明 |
|---|---|---|---|
| 会社名 | テキスト | ○ | 来訪者の所属会社名 |
| 代表来訪者名 | テキスト | ○ | 主要来訪者のフルネーム |
| 来訪者人数 | 数値（1以上） | ○ | 来訪者の総人数 |
| 当社担当者名 | テキスト | ○ | 対応する当社スタッフ名（ログインユーザーの情報から自動入力） |
| 来訪予定日 | 日付 | ○ | 来訪予定日 |
| 備考 | テキストエリア | 任意 | 目的・注意事項など |

#### 処理仕様
- 「登録する」ボタン押下時、Server Action `createVisit` を実行
- 登録データに `staff_user_id`（ログインユーザーのID）と `status: 'scheduled'` を自動付与
- 登録成功時：`/visits` にリダイレクト
- 登録失敗時：エラーメッセージを画面上部に表示

---

## 4. 来訪一覧機能

### 画面：`/visits`

#### 概要
全来訪予定・実績を一覧表示し、絞り込み検索ができる画面。

#### 絞り込み条件

| 条件 | 形式 | 一致方式 |
|---|---|---|
| 会社名 | テキスト | 部分一致（大文字小文字不問） |
| 担当者名 | テキスト | 部分一致（大文字小文字不問） |
| ステータス | セレクトボックス | 完全一致 |
| 日付 | 日付 | 完全一致（来訪予定日） |

- 複数条件はAND検索
- 「絞り込み」ボタン押下で検索実行（GETリクエスト、URLパラメータに条件を保持）
- いずれかの条件が入力されている場合「クリア」リンクを表示

#### 一覧表示項目（デスクトップ）

| 列 | 内容 |
|---|---|
| 来訪日 | 来訪予定日（年月日・曜日） |
| 会社名 | 来訪者の会社名 |
| 代表者 | 代表来訪者名 |
| 人数 | 来訪者人数 |
| 担当者 | 当社担当者名 |
| 入室 | 入室時刻（未記録は「—」） |
| 退室 | 退室時刻（未記録は「—」） |
| 状態 | ステータスバッジ |
| 操作 | 詳細リンク |

- モバイル表示ではカード形式に切り替わる
- 一覧は来訪予定日の降順（新しい順）

## 5. 来訪詳細・編集・キャンセル機能

### 画面：`/visits/[id]`

#### 概要
来訪の詳細確認、登録内容の編集、キャンセルを行う画面。

#### 表示内容

| 項目 | 表示条件 |
|---|---|
| 会社名 | 常時 |
| ステータスバッジ | 常時 |
| 代表来訪者 | 常時 |
| 来訪者人数 | 常時 |
| 当社担当者 | 常時 |
| 来訪予定日 | 常時 |
| 入室時間 | entry_time が記録されている場合 |
| 退室時間 | exit_time が記録されている場合 |
| 備考 | notes が入力されている場合 |

#### 編集機能
- status = `scheduled` の場合のみ編集フォームを表示
- 編集可能項目：事前登録と同じ全項目
- 「更新する」ボタン押下で Server Action `updateVisit` を実行
- 更新成功時：同詳細画面にリダイレクト

#### キャンセル機能
- status = `scheduled` の場合のみキャンセルボタンを表示
- 「この来訪をキャンセルする」ボタン押下で Server Action `cancelVisit` を実行
- status を `cancelled` に更新し、`/visits` にリダイレクト

## 6. キオスク機能（iPad入退室記録）

### 画面：`/kiosk`

#### 概要
受付に設置したiPadから、来訪者の入室・退室時刻を記録する専用画面。認証不要で利用可能。

#### 表示内容
- 本日（scheduled_date = 今日）かつ status が `scheduled` または `checked_in` の来訪を表示
- ヘッダーに現在時刻をリアルタイム表示（1秒ごと更新）

#### 来訪カード表示項目

| 項目 | 内容 |
|---|---|
| 会社名 | 来訪者の会社名（大きく表示） |
| 代表者・人数 | 「〇〇 ほかN名」形式 |
| 担当者 | 当社担当者名 |
| 入室中バッジ | status = checked_in の場合に表示 |
| 入室時刻 | 記録済みの場合に表示 |
| 退室時刻 | 記録済みの場合に表示 |

#### 入室記録ボタン
- 表示条件：status = `scheduled`
- 押下時：PATCH `/api/visits/[id]/checkin` を呼び出し（action: "entry"）
- 処理内容：`entry_time` に現在時刻を記録、status を `checked_in` に更新
- 成功時：ボタンが「✓ 記録しました」に変わり、1.5秒後に画面を再読み込み

#### 退室記録ボタン
- 表示条件：status = `checked_in`
- 押下時：PATCH `/api/visits/[id]/checkin` を呼び出し（action: "exit"）
- 処理内容：`exit_time` に現在時刻を記録、status を `completed` に更新
- 成功時：同上

#### API仕様：`PATCH /api/visits/[id]/checkin`

**リクエスト**
```json
{ "action": "entry" | "exit" }
```

**レスポンス（成功）**
```json
{ /* 更新後のvisitオブジェクト */ }
```

**エラーレスポンス**

| ステータス | 条件 |
|---|---|
| 400 | action が "entry"/"exit" 以外 |
| 400 | entry: すでに入室済み / exit: まだ入室していない |
| 404 | 指定IDの来訪が存在しない |
| 500 | DB更新失敗 |

## 7. ステータス遷移

```
[事前登録]
    │
    ▼
scheduled（予定）
    │
    │ 入室記録
    ▼
checked_in（入室中）
    │
    │ 退室記録
    ▼
completed（完了）

scheduled ──キャンセル──▶ cancelled（キャンセル）
```
